# v47 文字化け表示修正版

## 修正内容
- CSV取り込み時の文字コード判定を強化
- UTF-8 / Shift_JIS の両方で読み、文字化けが少ない方を採用
- 全体履歴・商品別履歴の商品名は、履歴に保存された商品名より商品マスター名を優先表示
- 過去に文字化けして保存された履歴も、商品マスターを正しい名前で再取り込みすれば表示上は改善します

## 重要
すでにSupabaseへ文字化けした商品名で保存されたデータ自体は、CSV読み込み処理を直しても自動修復されません。
正しいCSVをもう一度「追加・更新で取り込み」してください。
その後、履歴表示では商品マスター名が優先されます。

不要です。
