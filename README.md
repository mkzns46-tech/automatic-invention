# v40 1万商品軽量版

## 変更内容
- 商品マスター1万件規模を想定した軽量化
- 起動時の全体履歴は最新100件だけ取得
- チェック履歴も最新100件だけ取得
- 商品別履歴はバーコード入力時に、その商品の履歴だけ取得
- スマホの起動負荷を軽減
- CSV取り込み・カメラ読取・手入力は維持

## 重要
商品データ1万件自体は可能です。
重くなる原因は「全履歴を全部表示すること」です。
この版では履歴取得を必要時だけに分けています。

## SQL操作
不要です。
