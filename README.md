# v33 iPhoneカメラ対応版

## 変更内容
- iPhone Chrome / Safari でも動きやすい html5-qrcode 方式を追加
- BarcodeDetector 非対応でもカメラ読取を試せるように変更
- 手入力・外付けバーコードスキャナ機能はそのまま維持
- スキャン成功時は在庫変動登録と商品別履歴に連動

## 注意
カメラ利用にはHTTPSとカメラ許可が必要です。
iPhoneで開く場合は、LINE内ブラウザではなくSafariまたはChromeで直接開いてください。

## SQL操作
不要です。
