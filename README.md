# ARICO TOKYO 履歴管理シート ログイン必須版

## 内容
ポータルから入った場合だけ、履歴管理シートを開けるようにした版です。

## 変更点
- `app.js` の先頭にログインガードを追加
- 未ログインで履歴管理シートURLへ直接アクセスすると、ARICO PORTALへ戻ります
- ポータルから `?auth=ARICO_PORTAL_2026` 付きで開いた場合だけ利用できます
- 認証後はURLから `auth` を自動で消します
- 在庫変動登録カードに商品名検索欄を追加
- 全体履歴の区分検索で、条件に合う最新50件をDBから取得して表示

## ポータル側の在庫管理リンク例

```js
window.location.href = "https://履歴管理シートのURL/?auth=ARICO_PORTAL_2026";
```

実際の履歴管理シートURLに置き換えてください。

## 差し替えるファイル
履歴管理シート側のGitHub/Vercelプロジェクトに以下をアップロードまたは上書きしてください。

- index.html
- style.css
- app.js
- package.json

## 注意
これは簡易ログインガードです。
社外公開や厳密な権限管理をする場合は、次の段階でSupabase Authなどに移行するのがおすすめです。
