# v41 高速起動版

## 変更内容
- 起動時に商品マスター全件を読み込まない方式へ変更
- 商品はバーコード入力時にSupabaseから1件だけ取得
- 商品1万件規模でも起動が軽くなります
- 商品別履歴も該当バーコード分だけ取得
- 全体履歴は最新100件だけ
- 担当者リストは通常読み込み

## メリット
- 起動が速い
- スマホが軽い
- 商品数が多くても動きやすい

## 注意
初回バーコード入力時に、その商品だけ通信して確認します。

不要です。
