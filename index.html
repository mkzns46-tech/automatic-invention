# 追加設定 ## Supabase SQL 備品転用の確認者と確認日時を保存するため、デプロイ前に `supabase_equipment_use_confirmation.sql` を Supabase で実行してください。 ## Vercel 環境変数 `api/smaregi-products.js` はスマレジ POS API の `GET /products` と `GET /stock` を利用します。 必要な環境変数: - `SMAREGI_CONTRACT_ID` - `SMAREGI_ACCESS_TOKEN` 任意: - `SMAREGI_STORE_ID` - 指定時は、その店舗の在庫だけを商品マスターへ反映します。 - `SMAREGI_POS_API_BASE_URL` - 未指定時は `https://api.smaregi.jp/{契約ID}/pos` を利用します。 アクセストークンには `pos.products:read` と `pos.stock:read` が必要です。
